# Recursos de terceros

Los logos y CSS de identidad ApiTech proceden del ZIP MK5 aportado por el equipo y se conservan para esta migración.

Font Awesome Free 6.5.0 se incluye localmente bajo `static/vendor/fontawesome` para evitar dependencia visual de un CDN. Atribución: Fonticons, Inc., https://fontawesome.com. Licencias del proyecto: iconos CC BY 4.0, fuentes SIL OFL 1.1 y código MIT; https://fontawesome.com/license/free. El encabezado del CSS conserva su atribución. Las fuentes WOFF2 corresponden a los estilos solid, regular y brands.

Django, mysqlclient, requests, python-dotenv, bcrypt, openpyxl y ReportLab se instalan como dependencias; no se redistribuye su código completo ni el entorno virtual en el ZIP. Sus versiones están en requirements.txt y requirements-mysql.txt.
